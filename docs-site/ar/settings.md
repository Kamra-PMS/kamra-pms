# الإعدادات

كل ما يضبطه العقار موجود في **الإعدادات** (رمز الترس في الشريط الجانبي). لكل
جزء من Kamra صفحته الخاصة، وكل صفحة توضح من يحق له تغييرها. كل تغيير يُفحص
مقابل حدوده ويُسجَّل في **سجل النشاط** مع القيمة القديمة والجديدة.

![مركز الإعدادات: صفحات مجمّعة في العقار، والوحدات، والوصول، والتكاملات، وأنت](/img/settings/hub.png)

## ابحث عن إعداد

اكتب في **البحث في الإعدادات** (أو اضغط **/**) واختر النتيجة. تُفتح الصفحة
الصحيحة وتنتقل إلى الإعداد.

![البحث في الإعدادات عن عدم الحضور والانتقال إليه](/img/settings/search.gif)

## غيّر إعدادا

1. افتح الصفحة (مثلا **الاستقبال**).
2. غيّر القيم. يظهر بجانب كل إعداد تغيّر نقطة كهرمانية، وشريط في الأسفل
   يعدّ التغييرات غير المحفوظة.
3. اضغط **حفظ التغييرات** في ذلك الشريط (أو **تجاهل**). إذا كانت قيمة خارج
   النطاق ("لا يمكن أن تتجاوز 60")، لا يُحفظ شيء وتوضح الصفحة أي قيمة.

الإعداد الذي ليس على قيمته الافتراضية يظهر تحته **إعادة التعيين إلى
الافتراضي**.

![صفحة إعدادات وحدة مع أقسامها ومفتاح الوحدة](/img/settings/module-page.png)

ترى فقط الصفحات التي يحق لدورك تغييرها. سطر **غيّره** تحت عنوان كل صفحة
يعرض تلك الأدوار، ويستطيع مدير الفندق تغييرها كلها.

## الصفحات

| الصفحة | ما فيها | الدليل |
| --- | --- | --- |
| العقار | الاسم، والاسم القانوني، والشعار، والدولة (التي تحدد حزمة الضرائب والفوترة)، والعملة، والمنطقة الزمنية، والعنوان، والرقم الضريبي | [إعداد الدولة](/country-setup) |
| سياسات الإقامة | أوقات تسجيل الوصول والمغادرة، والحد الأدنى للإقامة، ومهلة الإلغاء المجاني، ورسوم الإلغاء وعدم الحضور، والعربون | [الحجوزات](/ar/reservations) |
| الخصوصية والبيانات | مدة الاحتفاظ ببيانات الضيوف ورسائلهم، وجهة الاتصال للخصوصية | |
| الاستقبال | الوصول، والحجوزات المؤقتة، وعدم الحضور، وعرض اليوم | [مكتب الاستقبال](/ar/front-desk) |
| التدبير المنزلي | مواعيد المهام النهائية، وتجهيز الغرف، وأسعار الغسيل | [التدبير المنزلي](/ar/housekeeping) |
| العمليات | مواعيد طلبات الضيوف النهائية حسب الأولوية | [العمليات](/ar/operations) |
| المأكولات والمشروبات | القبول التلقائي لأمر المطبخ، وإيصالات الإبطال، ومهلة حجز الطاولات، وطابعات المطبخ، وفحص سرعة POS | [المأكولات والمشروبات](/ar/fnb) |
| المآدب والمجموعات | هوامش عروض الأسعار، ومراحل الدفع، والمتابعات | [المآدب](/ar/banquets) |
| الإيرادات | إلى أي حد يمكن للفندق البيع فوق السعة، والتسعير حسب الطلب | [الإيرادات](/ar/revenue) |
| المالية | ضريبة الغرف، والرسوم، وضوابط أمين الصندوق (PIN، وحدود الاسترداد النقدي) | [الفوترة](/ar/billing) |
| محرك الحجز | صفحة `/book` العامة: تشغيل أو إيقاف، حجز فوري أو طلب حجز، طريقة دفع الضيوف | [محرك الحجز](/ar/booking-engine) |

صفحات أجزاء Kamra التي يمكنك إيقافها (التدبير المنزلي، والعمليات،
والمأكولات والمشروبات، والمآدب، والإيرادات، ومحرك الحجز…) فيها مفتاح
**الوحدة مفعلة** في الأعلى. مدير الفندق وحده يستطيع تشغيل الوحدات
وإيقافها. الوحدة الموقوفة تختفي من الشريط الجانبي للجميع، وتُخفى أدواتها عن
وكلاء الذكاء الاصطناعي.

## أضف موظفين وامنحهم الوصول

**الإعدادات → الموظفون والصلاحيات** تعرض كل من يستطيع تسجيل الدخول، مع
أدوارهم والعقارات التي يصلون إليها.

![الموظفون والصلاحيات: أدوار كل شخص ووصوله إلى العقارات](/img/settings/staff.png)

1. اضغط **إضافة موظف**.
2. أدخل **الاسم الكامل** و**البريد الإلكتروني** (يسجّل الدخول به).
3. اختر **الأدوار**. كل دور يوضح ما يفتحه.
4. اختر **الوصول إلى العقارات**: كل العقارات (بما فيها التي تُضاف لاحقا)،
   أو بعضها فقط.
5. اترك **أرسل لهم رابطا لتعيين كلمة المرور** مفعلا لإرسال دعوة، أو أوقفه
   وشارك الوصول بنفسك.

![لوحة إضافة موظف مع وصف الأدوار](/img/settings/add-staff.png)

لتغيير بيانات شخص لاحقا، اضغط **إدارة** في صفه. من هناك تستطيع تغيير
الأدوار والعقارات، أو **إعادة تعيين PIN أمين الصندوق**، أو **تعطيله**.
الموظفون المعطّلون لا يستطيعون تسجيل الدخول، ويبقى سجلهم محفوظا. لا تستطيع
تغيير وصولك أنت، ولا يغيّر وصول مسؤول تقنية المعلومات إلا تقنية المعلومات.

## ماذا يستطيع كل دور

**الإعدادات → الأدوار والصلاحيات** تعرض التطبيقات التي يفتحها كل دور وصفحات
الإعدادات التي يحق له تغييرها. الأدوار حزم ثابتة: كل شاشة، واستدعاء API،
وأداة ذكاء اصطناعي تفحصها على الخادم.

![مصفوفة الأدوار: التطبيقات التي يفتحها كل دور والإعدادات التي يحق له تغييرها](/img/settings/roles.png)

| الدور | العمل اليومي |
| --- | --- |
| مدير الفندق | يدير العقار: كل التطبيقات، وكل الإعدادات، والموظفون والوصول |
| الاستقبال | الحجوزات، وتسجيل الوصول والمغادرة، والضيوف، والفواتير، وصندوق أمين الصندوق |
| مدير الإيرادات | الأسعار، والمواسم، وحدود الأسعار، والقنوات، ومحرك الحجز، ومبيعات المآدب |
| المالية | الفوترة، والدفاتر، والتدقيق الليلي، والتصدير، وضوابط الضرائب وأمين الصندوق |
| مدقق ليلي | نهاية اليوم: الوصول، والمغادرة، وإغلاق الصندوق، وحزمة التدقيق |
| مشرف التدبير المنزلي | لوحة الغرف، والفحص، ومواعيد المهام، وأسعار الغسيل |
| التدبير المنزلي | مهامهم، وحالة الغرف، والمفقودات، وغالبا على تطبيق الهاتف |

تقنية المعلومات (مدير النظام) تدير أيضا مفاتيح المطورين وتضيف العقارات.

## أوقف الوحدات

**الإعدادات → الوحدات** تعرض كل وحدة مع مفتاحها، لتوقف ما لا يشغّله هذا
العقار (دار ضيافة بلا مطعم توقف المأكولات والمشروبات). تخرج تطبيقاتها من
المشغّل والبحث وأدوات وكيل الذكاء الاصطناعي للجميع. الاستقبال والإدارة
مفعّلان دائما. لا يُحذف شيء، وإعادة تشغيل الوحدة تعيدها كما كانت.

![الإعدادات → الوحدات](/img/settings/modules.png)

## التكاملات

- **المدفوعات**: البوابة المستخدمة لروابط الدفع (الدفعات المقدمة،
  والتأمينات، وتسوية الفاتورة). البوابات المتاحة تعتمد على حزمة الدولة.
  راجع [الفوترة](/ar/billing).

  ![إعدادات المدفوعات](/img/settings/payments.png)

- **مساعد الذكاء الاصطناعي**: استخدم مفتاح الذكاء الاصطناعي الخاص بك (أي
  خدمة متوافقة مع OpenAI) لـ **وكيل كامرا** في الواجهة. تُزال حقول اتصال
  الضيف وهويته قبل إرسال أي شيء إلى النموذج.

  ![إعدادات مساعد الذكاء الاصطناعي: المزوّد والنموذج والمفتاح](/img/settings/ai.png)

- **وصول الذكاء الاصطناعي عبر MCP** (تحت الوصول): من يحق له ربط Claude أو
  ChatGPT أو عميل MCP آخر (بلا وصول، أو MCP Read، أو MCP Manage، لكل شخص)،
  وهل وصول الذكاء الاصطناعي مفعّل هنا، و**حظر أدوات الكتابة**، والأدوات
  المحظورة منفردة، والعملاء المتصلون مع **قطع الاتصال**، وعناوين دخول OAuth
  إضافية (لتقنية المعلومات فقط). راجع
  [من يمكنه استخدام MCP](/ai-and-mcp#who-can-use-mcp).

  ![وصول الذكاء الاصطناعي عبر MCP: مفاتيح العقار، ودور MCP لكل شخص، والعملاء المتصلون، والأدوات المحظورة](/img/settings/ai-access.png)
- **الفوترة الإلكترونية ZATCA**: تظهر للسعودية فقط. راجع
  [إعداد الدولة](/country-setup).

## المظهر

**الإعدادات → المظهر** تحدد السمة (فاتحة، أو داكنة، أو حسب النظام)
واللغة
لهذا المتصفح فقط. اختيار العربية يحوّل التخطيط إلى الاتجاه من اليمين إلى
اليسار.

![المظهر: السمة واللغة](/img/settings/appearance.png)

## معلومات مفيدة

- الإعدادات لكل عقار. إذا كان لديك عدة عقارات، بدّل العقار أعلى الشاشة قبل
  تغييرها.
- لا شيء آخر يكتب هذه القيم: التدقيق الليلي ومحرك الحجز ونقطة البيع تقرأ
  كلها الإعدادات نفسها، فيسري التغيير فورا.
- سجل النشاط (**الإدارة → سجل النشاط**) يعرض من غيّر أي إعداد، ومتى، ومن أي
  قيمة إلى أي قيمة.
- لمعرفة من سجّل الدخول إلى Kamra ومتى، اختر **دخول الموظفين** في عامل
  تصفية سجل النشاط. يعرض عمليات الدخول والخروج ومحاولات الدخول الفاشلة
  لموظفي هذا العقار. لمدير الفندق والمالية وتقنية المعلومات فقط.

## للمطورين

الصفحات والقيم تأتي من سجل واحد في `kamra/settings.py`
(`settings_schema`، `save_settings`)، والكود يقرأ القيمة باستخدام
`get_setting(property, key)`. الموظفون والأدوار في `kamra/staff.py`. راجع
[مرجع API](/api-reference).
