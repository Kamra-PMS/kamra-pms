# أدلة حسب الدور

ابحث عن وظيفتك، ثم عن الدليل لكل مهمة تقوم بها. كل دليل يعرض الشاشات
بالصور ومقاطع قصيرة.

## الاستقبال

| تحتاج إلى… | الدليل |
| --- | --- |
| رؤية الوصول والمغادرة والضيوف المقيمين اليوم | [الاستقبال → اليوم](/ar/front-desk) |
| تسجيل وصول ضيف، وطباعة بطاقة التسجيل، ومسح الهويات | [الاستقبال → تسجيل الوصول](/ar/front-desk) |
| استقبال حجز مباشر | [الاستقبال → حجز مباشر](/ar/front-desk) |
| إنشاء حجز أو تغييره أو إلغاؤه | [الحجوزات](/ar/reservations) |
| نقل ضيف، أو تمديد إقامة، أو استخدام مخطط الغرف | [الحجوزات](/ar/reservations) |
| ترحيل رسوم، أو استلام دفعة، أو تقسيم فاتورة | [الفوترة](/ar/billing) |
| تسجيل مغادرة ضيف وإعطاؤه فاتورة | [الاستقبال → تسجيل المغادرة](/ar/front-desk) و[الفوترة](/ar/billing) |
| فتح الصندوق وإغلاقه | [الفوترة → أمين الصندوق](/ar/billing) |
| تسجيل طلب ضيف | [طلبات النزلاء](/ar/operations) |
| الرد على الضيوف عبر WhatsApp | [WhatsApp](/whatsapp) |

## مساعدو الذكاء الاصطناعي

- **وكيل كامرا** (في الشريط الجانبي، إذا أضاف المسؤول مفتاح ذكاء اصطناعي):
  اسأل بكلمات بسيطة، مثل "من سيصل اليوم؟" أو "أعطني سعر غرفة مزدوجة لعطلة
  نهاية الأسبوع" أو "ألغِ RES-2026-0142، بطلب من الضيف". يقدّم عرض السعر
  قبل الحجز، ويعرض المعاينة قبل الإلغاء، وكل إجراء يقوم به يظهر في سجل
  النشاط.
- **Claude عبر MCP**: **وكيل كامرا → اربط ذكاءك الاصطناعي → ربط Claude**.
  يعمل باسمك، وبأدوارك. راجع [اربط ذكاءك الاصطناعي](/ai-and-mcp).
